# Generated model compatibility with Drogon 1.9.13

CI pins Drogon to 1.9.13 because of the request parsing regression documented in
`drogon-1.9.14-expect-100-continue-regression.md`. Models generated by newer
`drogon_ctl` versions call `drogon::utils::utf8Length`, which is not available
in 1.9.13. The checked-in models instead use `gnp::utils::utf8Length` from
`utils/Utf8Length.h`, matching the newer Drogon implementation's code-point
counting and malformed-byte behavior.

When regenerating models with a newer `drogon_ctl`, include
`utils/Utf8Length.h` in each generated `.cc` file that calls `utf8Length` and
replace `drogon::utils::utf8Length` with `gnp::utils::utf8Length`. Do not
replace this with a byte count: multibyte characters count as one code point.
The helper can be removed once all supported builds use a Drogon version that
provides the upstream function and the request parsing regression is resolved.
